# UAT script

For a peer who has never seen EditGuard. Do not help unless they are stuck for 2 minutes; note where they got stuck.

1. Open `http://localhost:8000` and enter the API key given to you.
2. Filter to English Wikipedia, minimum score 0.8.
3. Open the top flagged edit's diff on Wikipedia. Decide: vandalism, good faith, or unsure.
4. Read EditGuard's reason. Did it match what you saw? Mark the flag Correct or Wrong.
5. Repeat for 30 edits.
6. Answer: What was confusing? What would make you trust a flag more? Would this save a patroller time?

Record: completed unaided (yes/no), minutes per edit, confusions, answers.
